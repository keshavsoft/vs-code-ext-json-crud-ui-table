# vs-code-ext-json-crud-ui-init 🚀

Modern VS Code extension for instantly generating CRUD HTML UI pages with relative JavaScript files directly from the Explorer right-click menu.

Generate beautiful UI templates, navigation headers, CRUD pages, and starter frontend structure within seconds.

---

directly from the VS Code Explorer.

---

# 🖼️ Workflow

## Step 1

Right-click inside VS Code Explorer

---

## Step 2

Select:

```bash
Ui showHtml
```

---

## Step 3

A CRUD UI Generator window opens.

Available options:

- 📄 Header Only
- 📋 With Header

---

# ⚡ Available UI Generators

---

# 📄 Header Only

Creates:

- HTML file
- Relative JS file
- Navigation header only

---

## 🛠️ Generated Structure

```bash
Customers/
│
├── index.html
└── index.js
└── script.js

```



---

# 📋 With Header

Creates:

- Navigation header
- CRUD table UI
- Relative JS file
- Full starter CRUD page

---

## 🛠️ Generated Structure

```bash
Customers/
│
├── index.html
└── index.js
└── script.js
```

---

# 🛠️ Command

| Command | Description |
|---|---|
| `showHtml` | Opens CRUD UI Generator window |
